# 录音与转写指南

**简体中文** · [English](RECORDING_TRANSCRIPTION.en.md)

本指南描述当前源码分支，下载发布版的可用功能取决于平台版本。
完整行为契约见 [FEATURES.md](FEATURES.md)，原生验证见[开发指南](DEVELOPMENT.md)。

<a id="record-locally"></a>

## 本地录音

1. 从 macOS 菜单栏或 Windows 托盘选择**开始录音**，也可在快捷键设置中指定专用录音快捷键。
2. 在准备窗口选择系统声音、麦克风或两者，至少开启一个音源。
   关闭转写即可在不使用云服务的情况下录音。
3. 开始录音后可暂停/继续、重新开始、丢弃或停止。
   停止保存纯音频 M4A；转写失败不表示已保存的录音失败。
4. 通过已配置的录制输出操作和 Quick Access 访问音频。
   开启历史时，音频与其它录制一起显示；关闭历史不影响保存音频。

录屏仍需先选择区域，再从 **One Shot → 录屏** 开始。
录制准备面板包含本次转写、AI 和语音语言选项。
GIF 或未开启音源的录制不能使用转写。开始时记住选项；取消准备不保存草稿。

macOS 录音内部使用私有的 32 × 32 物理像素、1 fps 屏幕流，
仍需屏幕录制权限并显示系统指示；选择麦克风时还需麦克风权限。
临时视频仅用于恢复，在音频通过验证、处理状态持久化前保留，绝不作为视频交付或写入历史。
Windows 纯录音使用 WASAPI，不创建屏幕流。
转写流程不需要 Apple Speech 权限或本地模型。

<a id="configure-optional-cloud-transcription"></a>

## 配置可选云转写

| 设置 | macOS | Windows |
| --- | --- | --- |
| 语音与存储凭据 | AI 功能 → AI 转写 | 录制设置 |
| 可选 AI 整理的文字模型 | AI 功能 / Agent LLM 配置 | 录制设置中的文字模型配置 |
| 单次录制同意与语言 | 录音准备或 One Shot 录制面板 | 录音准备或 One Shot 录制面板 |
| 已保存任务与内容 | 转写结果 | 转写结果 |

使用自己的火山引擎语音 API Key，以及专用 TOS Access Key ID / Secret Access Key。
语音 Key 本身不授予对象存储权限。应用使用文件识别 2.0，无需填写模型 ID 或任意 ASR 上传 URL。

**保存**仅在本地保存配置。**保存并测试**还会初始化或验证私有存储，
发送公开音频样本进行计费服务检查。确认前阅读费用提示。
测试成功不会自动开启上传，仍需在录制准备中选择转写。凭据输入留空保留已保存值。

默认初始化使用北京区域私有标准存储，过期规则限定到本次安装前缀。
高级已有存储须满足应用私有存储检查。未完成任务与删除重试需要保留凭据。
存储设计与历史账户测试见[实施方案](VOLCENGINE_TRANSCRIPTION_REFACTOR_PLAN.md)。

选择 **Auto** 自动识别语音语言，或指定一种支持语言。
仅在希望已配置文字模型润色、整理原文时开启 AI。录制与转写均可不使用 AI。

<a id="find-export-and-retry-results"></a>

## 查看、导出和重试

从菜单栏/托盘中“开始录音”旁打开**转写结果**，或从对应历史项的转写操作进入。
可搜索、筛选音频/视频任务，选择结果并查看原文、润色文字或整理笔记。
复制与保存/导出作用于当前选中内容。转写导出保留时间戳，整理笔记保留来源引用。

关闭结果窗口不取消后台处理。结果在重启后保留，且独立于剪贴板历史。
删除源媒体或历史到期，不删除已保存转写。

| 情况 | 预期行为与后续操作 |
| --- | --- |
| 本地音频保存失败 | 保留恢复媒体；可能取消退出，以便重试保存。 |
| 提交中断或结果不确定 | 恢复时查询持久化请求 ID，不自动发起第二个付费任务。 |
| 云任务终态失败，需要重新提交 | 阅读并显式确认重新提交的费用提示。 |
| AI 整理失败 | 原文仍可用；从已保存文字重试，不重复语音识别。 |
| 云端删除待完成 | 后台维护使用任务原账户重试清理。 |

长音频切成不重叠分段，每段最多四小时、256 MiB，并保留绝对时间戳。
优先在较安静位置切分，但不保证自然句界。
系统与麦克风角色保持独立；说话人标签仅在分段内有效，不代表已验证身份。

<a id="data-and-credentials"></a>

## 数据与凭据

选定音频直接上传至用户私有 TOS，供语音服务读取，不上传视频帧。
临时签名读取 URL 在 24 小时后失效；即时删除和独立重试之外，还配置两天过期规则兜底。
清理失败与转写失败分别处理；取消不能撤销已产生费用。

可选 AI 整理向配置的 LLM 端点发送转写文字与分句 ID，
不发送媒体文件、本地路径或视频帧。ShotPaste 不运营上传中转，云费用属于用户自己的账户。

macOS 凭据保存在按构建身份隔离的本地 UserDefaults 档案中，**不是 Keychain 加密**。
Windows 使用当前用户 DPAPI，包括已保存任务的账户快照。
两平台均从配置导出和诊断中排除凭据，Debug 与 Release 使用独立应用数据。
转写与笔记属于私有本地内容，管理备份或分享导出文件时应考虑这些数据。
见[安全模型](../SECURITY.md#security-model)。
