## ShotPaste for macOS @VERSION@

This is an independent stable macOS release. The Windows release follows its
own version and publication schedule.

### Download

- macOS 13+ on Apple Silicon: `ShotPaste-v@VERSION@-macOS-arm64.dmg`
- macOS 13+ on Intel: `ShotPaste-v@VERSION@-macOS-x86_64.dmg`
- Checksums: `SHA256SUMS.txt`

Read the macOS `START-HERE` file before first launch. The package uses
ShotPaste's persistent self-signed certificate.
