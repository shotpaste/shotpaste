ShotPaste @VERSION@ - macOS (Apple Silicon)
================================================

This DMG is signed with ShotPaste's persistent self-signed certificate.

INSTALL BEFORE FIRST LAUNCH:
Drag "ShotPaste.app" onto "Applications" in the DMG window, then launch the
installed copy from /Applications. Do not run ShotPaste directly from the DMG;
macOS privacy permissions are tied to the installed app's identity and path.

1. Download the DMG and SHA256SUMS.txt from the same GitHub Release.
2. Run:

     shasum -a 256 ShotPaste-v@VERSION@-macOS-arm64.dmg

   Compare the result with the matching DMG line in SHA256SUMS.txt.
3. Open the DMG and drag "ShotPaste.app" to Applications.
4. If Gatekeeper blocks the first launch, open System Settings > Privacy &
   Security, choose Open Anyway, and confirm.
5. Grant Screen Recording, Microphone, or Accessibility permissions only when
   you use features that require them.
