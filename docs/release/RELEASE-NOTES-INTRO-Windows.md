## ShotPaste for Windows @VERSION@

This is an independent stable Windows release. The macOS release follows its
own version and publication schedule.

### Download

- Windows 10/11 x64: `ShotPaste-v@VERSION@-Windows-x64-portable.zip`
- Checksums: `SHA256SUMS.txt`

Read the Windows `START-HERE` file before first launch. The package is not
currently Authenticode-signed.
